# Graveyard

1. Read `docs/RESEARCH_STATE.md` section 2 (closed directions) and section 4 (never quote).
2. Find the nearest closed entries to the idea. For each, open its evidence file and read the
   verdict and the number that closed it.
3. Answer plainly: closed (with the figure and file), adjacent (what is different and whether the
   difference is a new mechanism or just a new parameter), or open.
4. If it is genuinely open, name the closest published work from `docs/REFERENCES.md` and how the
   idea differs, and say which `docs/ROADMAP.md` item it belongs to or that it needs a new row.

A new parameter on a closed mechanism is not a new idea. Say so.
