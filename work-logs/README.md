# Work logs

One folder per person, named by GitHub handle, one file per month (`YYYY-MM.md`), newest entry
at the top. Each entry is a short update in the author's own words (what you worked on, what you
learned, what is next or blocking) followed by the evidence: commits, files and study runs since
the last entry. In Claude Code, `/log-work` gathers the evidence and asks for the update; it
never writes the update for you.
